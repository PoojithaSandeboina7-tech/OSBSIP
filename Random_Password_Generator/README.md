# Random Password Generator

## 📌 Project Overview

The Random Password Generator is a Python-based application that creates random passwords based on the user's selected requirements.

The user can choose the password length and character types such as uppercase letters, lowercase letters, numbers, and symbols.

## ✨ Features

- Minimum password length of 8 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Input validation
- Random password generation
- Option to generate another password
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Random module
- String module

2. Open the project folder in VS Code.
3. Open the Terminal.
