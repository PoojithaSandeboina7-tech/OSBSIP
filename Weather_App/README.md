# 🌦️ Basic Weather App

## 📌 Project Overview

The Basic Weather App is a Python-based application that provides
current weather information for a city entered by the user.

The application uses the OpenWeather API to retrieve real-time
weather data and displays the information in a simple command-line
interface.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 🌡️ Display feels-like temperature
- 💧 Display humidity
- ☁️ Display weather condition
- 💨 Display wind speed
- ❌ Handles invalid city names
- 🌐 Handles internet connection errors
- 🔄 Option to check another city
- 🔐 API key stored securely using environment variables

## 🛠️ Technologies Used

- Python
- OpenWeather API
- Requests library
- python-dotenv
- Environment Variables
